Research Orbit Control

A new control layer for the hidden problem on C:\

The problem is not a lack of meta-research assets. The problem is portfolio entropy: too many projects, too many partial apps, too many overlapping themes, and too little orchestration. The new solution is Research Orbit Control, a drive-native control tower that turns a scattered research estate into ranked fusion programs, merge queues, and execution decisions.

Problem

Unknown problem surfaced: hidden compound value is stranded across more than one hundred project directories, multiple HTML apps, and a growing root-level research layer.

Solution

Build a portfolio observability and orchestration app that scores themes, duplicate gravity, dark-matter assets, and fusion programs from a bundled and optionally live C:\ snapshot.

Output

An HTML app with live folder loading, import/export snapshot support, an intervention studio, and a WebR validation layer for the key rankings.

Data Sources

  • Bundled C:\ top-level directory snapshot captured on 28 March 2026.
  • Bundled C:\Projects directory inventory.
  • Bundled C:\HTML apps directory inventory.
  • Optional live folder refresh via the File System Access API for C:\, C:\Projects, or C:\HTML apps.

Core Models

  • Theme constellation: classify directories into reusable research themes such as bias, IPD, HTA, extraction, control, and living evidence.
  • Duplicate gravity: detect token families that imply repeated effort, fragmented lines of work, or merge candidates.
  • Dark-matter asset score: identify assets with high bridgeability but low orchestration coverage.
  • Problem hypothesis model: rank hidden portfolio failure modes such as entropy, bridge deficit, living-update lag, and validation fragmentation.
  • Fusion program engine: assemble executable programs that combine the most relevant projects and apps into one coherent next build.

Intervention Studio

The app includes a manual strategy tuner over impact, execution, reuse, novelty, and governance. That makes the solution adaptive: the user can prioritize safe consolidation, a field-reset moonshot, or control-first cleanup without changing the underlying drive scan.

Validation

WebR independently checks the headline metrics: total research items, research-root count, project count, app count, top hidden problem, top theme, top fusion program, mean dark-matter score, and duplicate-family count.
